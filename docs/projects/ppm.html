Image processing from first principles

A terminal-based C++ editor for ASCII PPM (P3) and PGM (P2) images. Working directly with pixel values made the underlying algorithms explicit: weighted grayscale conversion, Gaussian convolution and a Canny-style edge-detection pipeline.

How an image becomes an edge map

The processing pipeline

Gaussian smoothing reduces noise. Sobel filters estimate gradient magnitude and direction. Non-maximum suppression thins candidate edges; double thresholds separate strong and weak responses. Hysteresis keeps weak edges connected to strong ones.

Implementation focus

The project separates image representation from filters and includes tests. Gaussian blur strength is controlled by σ. For a fixed kernel size, convolution scales linearly with the number of pixels; allowing the kernel size to grow adds its own computational cost.
