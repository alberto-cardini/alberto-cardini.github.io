EduMeter

A course-review platform designed for students at the University of Florence.

Helping students choose courses

EduMeter is a web application designed for University of Florence students to share reviews of courses they have attended. The aim is to make student experience easier to discover when planning a study programme.

Under the hood

The Java backend uses JAX-RS and is packaged as a WAR for an application server such as Tomcat. It supports an in-memory development mode and persistent PostgreSQL storage, with JUnit tests.

Project status

The public repository is a development prototype. Its documented login endpoint accepts test PINs; production identity verification remains a separate step before a public release.
